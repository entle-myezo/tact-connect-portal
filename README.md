# TACT Connect Portal

BUild a modern, responsive church events and communication web application called TACT Connect for The Twelve Apostles Church in Trinity, South Africa, Africa & Interglobally.

The purpose of this application is to digitally transform the church's official Diary of Events 2026 into an easy-to-use platform where church members can view upcoming events, important dates, venues, announcements, and reminders.

The church motto is:

“ONE FOR ALL, ALL FOR CHRIST”

1. DESIGN DIRECTION

Create a clean, elegant, modern church-focused UI.

The design should feel:

Welcoming

Professional

Spiritual

Elegant

Modern

Easy for older and younger church members to use

Use a refined colour palette inspired by the church document/logo:

White as the main background

Deep purple as a primary colour

Gold/golden accents for important elements

Dark charcoal/black for text

Subtle gradients where appropriate

Do NOT make the application look like a generic corporate SaaS dashboard.

Use:

Rounded cards

Soft shadows

Elegant typography

Clear icons

Large readable text

Responsive layouts

Plenty of whitespace

Accessible buttons and navigation

The application must work beautifully on desktop, tablet and mobile.
